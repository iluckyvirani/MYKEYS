# 📘 Property Rent & Sale Platform

**Product Requirement Document (PRD)**

---

## 1. Introduction

This project is a **Property Rent & Sale Platform** that allows users to:

* Book properties for **short-term stays** (night-based)
* Rent properties for **long-term duration**
* Buy or sell properties
* Contact property owners through a **secure enquiry system**
* Promote properties for **faster rent or sale**

The platform supports both **users (customers)** and **property owners**, with multiple monetization options.

---

## 2. Objectives

* Provide a simple and trustworthy platform for property renting and selling
* Avoid direct exposure of owner contact details
* Offer premium listing and fast-selling options
* Support both **self-listing** and **assisted listing**
* Generate revenue through packages and promotions

---

## 3. Property Categories

### 3.1 Short-Term Rent (Night-Based Booking)

**Description:**

* Properties can be booked for a short duration (e.g., 1–30 nights)
* Pricing is calculated per night

**Example:**

* Price per night: ₹2,000
* Booking duration: 2 nights
* Total price: ₹4,000

**Key Features:**

* Check-in & check-out date selection
* Night-based price calculation
* Availability calendar
* Booking confirmation
* Optional online payment

---

### 3.2 Long-Term Rent

**Description:**

* Monthly rental properties
* Suitable for families, students, offices, etc.

**Key Features:**

* Monthly rent display
* Security deposit information
* Minimum stay duration
* Enquiry-based contact (no direct phone number)

---

### 3.3 Property Sale

**Description:**

* Property listed for selling
* Buyer sends enquiry to owner

**Key Features:**

* Fixed selling price
* Property details & media
* Secure enquiry system
* Featured promotion option

---

## 4. Property Listing Packages (Owner Side)

### 4.1 Package 1 – Basic / Self Listing

**Features:**

* Owner lists property on their own
* Manual image upload
* Basic property details
* Normal visibility in listing

**Target Users:**

* Budget-conscious owners
* Owners who manage listings themselves

---

### 4.2 Package 2 – Assisted Listing (Professional)

**Features:**

* Platform team support
* Professional photography
* Property video creation
* Optimized property description
* Better visibility and trust

**Target Users:**

* Owners who want professional marketing
* High-value properties

---

### 4.3 Package 3 – Featured / Fast Rent or Sale

**Features:**

* Property appears at the **top of listings**
* Featured badge
* Priority visibility on homepage & search results
* Time-based promotion (7 / 15 / 30 days)

**Target Users:**

* Owners who want fast results

---

## 5. User Side Features

### 5.1 Property Browsing

Users can:

* Browse all properties
* Filter by:

  * Rent type (Short-term / Long-term / Sale)
  * Location
  * Price range
  * Property type
* View images, videos, amenities, and map location

---

### 5.2 Enquiry System (Secure Contact)

**Important Rule:**
Owner phone number is **not visible publicly**

**Enquiry Flow:**

1. User clicks **“Enquiry Now”**

2. Form opens with:

   * Name
   * Mobile number
   * Message (optional)

3. If user is logged in:

   * Name & mobile auto-filled
   * Enquiry sent instantly to owner

4. Owner receives enquiry via:

   * Dashboard
   * Email / notification (optional)

---

### 5.3 Short-Term Booking Flow

1. Select check-in and check-out dates
2. View total price
3. Confirm booking
4. Payment (optional in MVP)
5. Booking confirmation

---

## 6. Owner Side Features

### 6.1 Owner Dashboard

Owners can:

* Add, edit, and delete properties
* Choose or upgrade listing packages
* Upload images and videos
* View enquiries
* Track featured listing duration

---

### 6.2 Enquiry Management

Owners can:

* View user contact details
* Respond to interested users
* Mark enquiry status:

  * New
  * Contacted
  * Closed

---

### 6.3 Promotion Management

Owners can:

* Promote property for fast rent/sale
* Choose promotion duration
* Monitor views & enquiries
